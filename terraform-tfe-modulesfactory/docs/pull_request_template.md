## Version bump

Add one of the following keywords **in the PR title** to control the version bump.
If no keyword is present, the pipeline defaults to a **patch** bump.

| Keyword in PR title | Effect | Example |
|---|---|---|
| `#minor` | Bumps the minor component, resets patch to 0 | `v1.2.3 → v1.3.0` |
| `#major` | Bumps the major component, resets minor and patch to 0 | `v1.2.3 → v2.0.0` |
| *(none)* | Bumps the patch component | `v1.2.3 → v1.2.4` |

**Examples of PR titles:**

```
fix: correct variable validation logic
feat: add support for no-code module #minor
breaking: rename module_provider variable #major
```
